# 隧道地质灾害AI预警系统 - 系统架构设计文档

## 1. 需求分析

### 1.1 项目背景
隧道在运营过程中可能面临塌方、涌水、岩爆、大变形等地质灾害，传统人工巡检效率低、响应慢。本系统通过在隧道内部署多种传感器实时采集数据，结合AI模型进行智能分析，实现地质灾害的早期预警。

### 1.2 核心目标
- 实时采集隧道各类监测数据（位移、应力、地下水、温度等）
- AI 智能分析数据趋势，识别异常
- 自动生成不同等级的预警信息
- 支持多端查看和预警通知

### 1.3 功能需求
| 模块       | 功能                   | 优先级 |
| ---------- | ---------------------- | ------ |
| 用户管理   | 登录、注册、角色权限   | P0     |
| 隧道管理   | 隧道信息增删改查       | P0     |
| 监测点管理 | 监测点增删改查         | P0     |
| 数据采集   | 传感器数据接收与存储   | P0     |
| 数据展示   | 历史数据查询、图表展示 | P1     |
| AI预警     | 智能分析、自动预警     | P0     |
| 预警管理   | 预警记录查询、处理     | P0     |
| 通知推送   | 短信/邮件/站内通知     | P2     |

### 1.4 非功能需求
- 响应时间：接口响应 < 500ms
- 并发能力：支持 500 并发用户
- 数据采集：支持每秒 1000 条数据写入
- 预警延迟：从数据异常到预警生成 < 10s

## 2. 系统架构设计

### 2.1 整体架构（分层架构）

```
┌─────────────────────────────────────────────────────────┐
│                     前端展示层 (Web/App)                 │
│            Vue3 + Element Plus / 微信小程序              │
└─────────────────────────────────────────────────────────┘
                            │ HTTPS
┌─────────────────────────────────────────────────────────┐
│                    接口层 (Controller)                   │
│        RESTful API / WebSocket / 文件上传下载            │
├─────────────────────────────────────────────────────────┤
│                    业务层 (Service)                      │
│   用户服务 │ 隧道服务 │ 监测服务 │ 预警服务 │ AI服务      │
├─────────────────────────────────────────────────────────┤
│                    数据层 (Repository/DAO)               │
│             Spring Data JPA / MyBatis-Plus              │
├─────────────────────────────────────────────────────────┤
│                     存储层 (Storage)                     │
│   MySQL(主数据) │ Redis(缓存) │ MinIO(文件)              │
└─────────────────────────────────────────────────────────┘
```

| 构建工具 | Maven                 | 3.9+   | 依赖管理               |

## 3. 数据库设计

### 3.1 ER 图（核心实体关系）

```
SysUser 1──N Warning
Tunnel 1──N MonitorPoint
Tunnel 1──N SensorData
Tunnel 1──N Warning
MonitorPoint 1──N SensorData
MonitorPoint 1──N Warning
Tunnel 1──N AiAnalysis
```

### 3.2 核心数据表

#### sys_user（用户表）
| 字段        | 类型         | 说明                |
| ----------- | ------------ | ------------------- |
| id          | BIGINT PK    | 主键                |
| username    | VARCHAR(50)  | 用户名，唯一        |
| password    | VARCHAR(100) | 密码（BCrypt加密）  |
| real_name   | VARCHAR(50)  | 真实姓名            |
| phone       | VARCHAR(20)  | 手机号              |
| email       | VARCHAR(100) | 邮箱                |
| role        | VARCHAR(20)  | 角色（ADMIN/USER）  |
| status      | TINYINT      | 状态（0禁用 1正常） |
| create_time | DATETIME     | 创建时间            |
| update_time | DATETIME     | 更新时间            |

#### tunnel（隧道表）
| 字段        | 类型          | 说明     |
| ----------- | ------------- | -------- |
| id          | BIGINT PK     | 主键     |
| name        | VARCHAR(100)  | 隧道名称 |
| location    | VARCHAR(200)  | 位置     |
| longitude   | DECIMAL(10,6) | 经度     |
| latitude    | DECIMAL(10,6) | 纬度     |
| length      | DECIMAL(10,2) | 长度(米) |
| description | VARCHAR(500)  | 描述     |
| status      | TINYINT       | 状态     |
| create_time | DATETIME      | 创建时间 |

#### monitor_point（监测点表）
| 字段        | 类型          | 说明                            |
| ----------- | ------------- | ------------------------------- |
| id          | BIGINT PK     | 主键                            |
| tunnel_id   | BIGINT FK     | 隧道ID                          |
| name        | VARCHAR(100)  | 监测点名称                      |
| type        | VARCHAR(50)   | 监测类型（位移/应力/水位/温度） |
| chainage    | DECIMAL(10,2) | 桩号(米)                        |
| description | VARCHAR(500)  | 描述                            |
| status      | TINYINT       | 状态                            |
| create_time | DATETIME      | 创建时间                        |

#### sensor_data（传感器数据表）
| 字段             | 类型          | 说明     |
| ---------------- | ------------- | -------- |
| id               | BIGINT PK     | 主键     |
| tunnel_id        | BIGINT FK     | 隧道ID   |
| monitor_point_id | BIGINT FK     | 监测点ID |
| data_type        | VARCHAR(50)   | 数据类型 |
| value            | DECIMAL(15,4) | 数值     |
| collect_time     | DATETIME      | 采集时间 |
| remark           | VARCHAR(500)  | 备注     |
| create_time      | DATETIME      | 创建时间 |

**索引**：(tunnel_id, collect_time)、(monitor_point_id, collect_time)

#### warning（预警记录表）
| 字段             | 类型         | 说明                               |
| ---------------- | ------------ | ---------------------------------- |
| id               | BIGINT PK    | 主键                               |
| tunnel_id        | BIGINT FK    | 隧道ID                             |
| monitor_point_id | BIGINT FK    | 监测点ID                           |
| warning_level    | VARCHAR(20)  | 预警等级（BLUE/YELLOW/ORANGE/RED） |
| title            | VARCHAR(500) | 预警标题                           |
| content          | TEXT         | 预警内容                           |
| suggestion       | TEXT         | 处置建议                           |
| warning_time     | DATETIME     | 预警时间                           |
| handle_status    | TINYINT      | 处理状态（0未处理 1已处理）        |
| handle_time      | DATETIME     | 处理时间                           |
| handle_remark    | VARCHAR(500) | 处理备注                           |
| create_time      | DATETIME     | 创建时间                           |

#### ai_analysis（AI分析记录表）
| 字段             | 类型        | 说明       |
| ---------------- | ----------- | ---------- |
| id               | BIGINT PK   | 主键       |
| tunnel_id        | BIGINT FK   | 隧道ID     |
| monitor_point_id | BIGINT FK   | 监测点ID   |
| analysis_type    | VARCHAR(50) | 分析类型   |
| input_data       | TEXT        | 输入数据   |
| ai_result        | TEXT        | AI分析结果 |
| risk_level       | VARCHAR(20) | 风险等级   |
| analysis_time    | DATETIME    | 分析时间   |
| create_time      | DATETIME    | 创建时间   |
